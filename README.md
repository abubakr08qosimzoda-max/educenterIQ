# LINGORA English Academy

"Learn English. Open Your World."

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis Smooth Scrolling
- Lucide React Icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables (optional):
   - `NEXT_PUBLIC_WHATSAPP_NUMBER`: Your academy WhatsApp number (country code + digits only, e.g., `992900000000`)
   - Server-side AI key (if connecting a live AI model in `app/api/chat/route.ts`).

3. Run the development server:
   ```bash
   npm run dev
   ```
